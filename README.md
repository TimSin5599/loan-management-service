# Учебное задание 5: Сервис управления кредитными счетами loan-management-service

### Цель

Управление жизненным циклом кредита:

- выдача кредита по результату оформления
- отображение состояния кредита
- досрочное погашение
- история операций

Notify: `Не забываем про сервис ApiGateway, именно с него начинаются запросы`

---

## 📌 **Функциональность**

 - Таблица `user_loans` хранит в себе данные по оформленному кредиту
 - Таблица `payments` хранит в себе историю платежей пользователя
